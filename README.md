# LEL

Generative Wojak PFP collection pipeline — target supply **6,666** (ERC-721 / Robinhood-compatible metadata).

Repo: [buildtogetherlabs/lel](https://github.com/buildtogetherlabs/lel)

## Status

Art pipeline first: normalize trait layers → prove **50 samples** → scale to 6,666 → mint packaging.

| Piece | Location |
|---|---|
| Raw trait layers | `layers_raw/wojak_pfp_project/` |
| Normalized 1000×1000 PNGs | `layers_normalized/` |
| Trait catalog / rules | `config/` |
| Generator scripts | `scripts/` |

| Contact sheet | `reports/preview_50.png` |

## Quick start

```bash
git clone https://github.com/buildtogetherlabs/lel.git
cd lel
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Rebuild trait catalog from raw layers
python scripts/curate_traits.py

# Normalize layers onto shared canvas (if regenerating)
python scripts/normalize_batch.py

# Preview one combo
python scripts/preview_trait.py \
  --face neutral_calm \
  --clothing black_hoodie \
  --hat cap_maga_red

# Generate proof set (50)
python scripts/generate_collection.py --count 50
python scripts/make_contact_sheet.py --out reports/preview_50.png

# Full collection (when ready)
python scripts/generate_collection.py --count 6666
```

## Layer order

Background → Face → Clothing → Mask → Accessory → Hat

## Config

- `config/canvas.json` — canvas size, anchors, category placement defaults
- `config/traits.json` — curated production traits (generated by `curate_traits.py`)
- `config/rules.json` — supply, seed, mask rate, compatibility rules
- `config/placement_overrides.json` — per-trait scale/offset tweaks
- `config/backgrounds.json` — solid background palette

## Notes

- Many source files were WebP labeled as `.png`; normalize step exports real PNG RGBA.
- Placement is automated with defaults; refine via `placement_overrides.json` after visual QA.
- Content/brand pass recommended before a Robinhood listing (meme/brand traits).
